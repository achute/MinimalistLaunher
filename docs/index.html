Core Philosophy

Engineered with Jetpack Compose, built entirely offline, and strictly privacy-first.

Text-Only UI

No colorful, addictive app icon badges. Clean, monochrome typographic labels and customizable fonts to keep your home screen calm.

Focus Profiles

Create distinct configurations (e.g. Deep Work, Evening). Swap out your 5 essential home screen apps based on your current context.

Zero Internet

No internet permission required. Zero analytics, telemetry, or network sockets. 100% local persistence securely stored on your device.

Digital Wellbeing

Set daily time limits per app. A built-in blocker enforces your limits and presents a mindful block screen when time is up.

Private Space

Seamless integration with Android 15's Native Private Space. Tie focus modes to require authentication and hide private apps securely.

Utility Dashboard

Swipe left for an offline dashboard featuring live battery telemetry, daily screen-time metrics, and a minimal to-do list manager.

Utility & Health Dashboard

Stay informed without falling into the scrolling trap. The built-in dashboard lives just one swipe away.

  • ✓ Live battery telemetry (temp, voltage, charging state).
  • ✓ Daily offline screen-time breakdown and insights.
  • ✓ Integrated minimalist task manager for daily goals.
  • ✓ Support for offline embedded Android system widgets.

Searchable Drawer & Gestures

Find what you need instantly and get back to living. The app drawer is built for speed and intent.

  • ✓ Instant text search across all installed apps.
  • ✓ Visual tags for hidden or Private Space apps.
  • ✓ Long-press context menu to pin, limit, or rename apps.
  • ✓ 4-way customizable gesture navigation (Swipe up, down, left, right).
